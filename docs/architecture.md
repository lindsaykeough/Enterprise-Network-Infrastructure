# Architecture

The project built a routed enterprise environment using Cisco, Juniper, and HPE equipment. Small transit networks connected Layer 3 devices, while VLAN-based user/server segments sat behind access and distribution switching.

Design goals included dynamic routing, segmentation, redundant gateways, IPv4/IPv6 support, secure remote administration, and centralized operational services.

The public portfolio intentionally omits the original institutional addressing and exact physical cabling map.
